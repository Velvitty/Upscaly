# 🔍 Upscaly：以无损为目标的图像放大工具（무손실 지향 확대기） `v1.2.2`

一款以无损为目标的图像放大工具。它只有一个文件（`upscaler.html`），所有计算都在浏览器内完成。
无需安装，也无需上传。图片不会离开你的设备。

## 1. 快速了解

### 这是什么工具

把小图放大，通常会变模糊、出现锯齿，或在轮廓周围出现白边。Upscaly 针对照片、插画、漫画、文档、标志、像素画等不同类型的图片，分别用合适的方式放大，在减少这些瑕疵的同时，尽可能保留原图所含的信息。

“以无损为目标”的意思是：复原时让放大后的图片再缩回原尺寸时与原图一致。放大不凭空编造原图中没有的内容，而是专注于把原图已有的信息以最合理的方式展开。轮廓强调、去锯齿等叠加在其上的校正，是在这一复原基础上为了观感进行的修饰，开启后结果会略微偏离原图信息（[2.1](#21-放大不会创造信息)）。

### 优点

- **无需安装。** 用浏览器打开一个文件即可。不联网也能用。
- **图片不会外传。** 不使用服务器，也不使用外部库。
- **自动适配。** 「自动」（자동）按钮会从 9 种类型中判断图片类型，并直接在这张图上测量来确定设置。
- **大倍率也撑得住。** 图片分块（tile）计算，每一行块压缩后再拼接，因此即使结果有数亿像素，也不会把未压缩的完整结果放进内存。不过压缩后的 PNG 文件会在保存完成前一直积累在内存中。
- **没有色带的渐变。** 以 8 位保存时混入细微的抖动，使放大后的天空、渐变不出现阶梯状的色带。也可以保存为 16 位 PNG。
- **保留手机照片的色彩。** iPhone 等拍摄的 Display P3 照片按 P3 读取、按 P3 保存，鲜艳的红色、绿色不会变得暗淡。
- **纹理恢复（可选）。** 可以给放大后变得像蜡一样光滑的皮肤、布料重新叠加细腻的纹理。默认关闭。
- **透明图片也干净。** 半透明边缘不会渗色。
- **准确与观感，两种目标。** 默认的「准确」（정확도）尽可能接近原图地放大。选择「观感」（체감）后，轮廓更陡、被埋没的明暗更突出，看起来更清晰。不会出现白边（光晕）。

### 使用方法

1. 用最新的浏览器打开 `upscaler.html`。
2. 点击**打开图像**（이미지 열기），或把图片拖到画面上，或直接粘贴。一次最多可打开 20 张，支持 JPEG·PNG·WebP·AVIF。
3. 选择**倍率**（배율）。有按宽高长度（1~12×）和按像素数（面积）两种方式；选择「自动」会选出本设备能处理到底的最大倍率（3~8×）。
4. 点击 **「自动：（推荐，建议）」（자동: (권장, 추천)）**。它会测量图片的类型和状态，填好下面的全部设置，并简短说明依据。如果看起来清晰比忠于原图更重要，请在**目标**（목표）中选择「观感」。
5. 点击**执行放大**（확대 실행）。若开启了**原图对比**（원본 비교），画面左半边显示用浏览器放大的原图，右半边显示结果。可拖动画面移动、用滚轮缩放，并使用**适应**（맞춤，F 键）、**1:1**、**原图对比**（C 键）按钮。
6. 用 **PNG 保存**（PNG 저장）保存当前图片，用**全部保存**（모두 저장）一次保存所有已处理的图片。

### 手动选择设置时

画面右侧的栏按处理顺序排列。

| 栏 | 作用 |
|---|---|
| 倍率（배율） | 放大多少倍。1× 表示不放大，只做整理 |
| 预设 · 自动（프리셋 · 자동） | 33 种预设或「自动」 |
| 目标（목표） | 「准确」（最接近原图，默认）或「观感」（提高轮廓斜率与局部对比度，看起来更清晰，强度 25~150%）。预设和「自动」不会改变它 |
| 重建核（재구성 커널） | 如何填充新像素（DCCI·像素画·Lanczos·Catmull-Rom·Mitchell·最近邻）、分步放大、振铃抑制、原图一致性 |
| 噪点·杂点清理（노이즈·잡티 정리） | 放大前去除噪点和 JPEG 痕迹 |
| 清晰度复原（선명도 복원） | 放大前还原拍摄·扫描时产生的模糊 |
| 去锯齿（계단 제거） | 只沿轮廓方向求平均来消除锯齿、轮廓重绘、JPEG 块缓解 |
| 轮廓强调（윤곽 강조） | 抑制光晕的反锐化掩模 |
| 纹理恢复（질감 되살리기） | 叠加原图中没有的细腻纹理。默认关闭，照片·绘画建议 20~30% |
| 色彩处理（색 처리） | 白平衡（预设和自动不会触碰的独立功能）、线性光计算、8 位抖动、16 位保存 |

复选框和滑块完全按你的选择工作。例如「分阶段放大」（단계로 나눠 확대）一旦开启，即使测量上更差也会分步。作为替代，旁边的指示灯会告诉你在当前图片上测得的结果。刚打开图片时，这个复选框的初始值由对图片的测量决定；若在测量完成前改动了复选框或按下「自动」，迟到的测量结果不会覆盖你的选择。

### 值得了解的事

- 已经多次缩小又重新保存过的图片，原有细节已经消失，无法再恢复。Upscaly 只是把剩下的信息以最合理的方式展开，不会编造不存在的面孔或文字。
- 有矢量原件（SVG、AI）的标志、图纸，使用原件总是更好。
- 放大到 8× 时，结果可达数百兆像素，耗时较长。进度显示中会给出剩余时间。

## 2. 原理

### 2.1 放大不会创造信息

数字图像是对连续场景按固定间隔采集的样本。比采样间隔更细的图案从一开始就没有被记录下来。因此放大的本质是“如何填充样本之间的空隙”，而填充方式不同，就会产生模糊、锯齿、振铃等瑕疵。

Upscaly 在选择填充方式时遵循三条原则。前两条是复原阶段（插值 → 单元范围 → 一致性）的约束，只有在开启相应复选框（「振铃·光晕抑制」（링잉·후광 차단）、「原图一致性校正」（원본 정합 보정））时才成立。

1. **不产生新的极值。** 复原出的像素位于其所属原图 2×2 单元中最暗值与最亮值之间（单元范围限制）。振铃和光晕是原图中没有的极值，因此在这一阶段不会出现。
2. **缩回去就是原图。** 使复原后的图片按光的面积平均缩回时与原图一致（原图一致性校正）。这意味着与原图的信息不矛盾。
3. **轮廓沿方向填充。** 跨越轮廓方向混合会使轮廓变模糊，沿坐标轴混合会产生锯齿。读取轮廓延伸的方向，只沿该方向填充（DCCI）。

两条约束（1·2）很难同时满足。满足其中一条，另一条就会略有偏差。因此采用交替满足两者的交替投影（[4.6](#46-交替投影)）。

复原之后的反锐化、方向平滑、轮廓重绘、纹理恢复属于为观感而修饰的阶段，不再遵守这两条约束。因此开启它们后的最终结果可能略微超出原图单元范围，或在缩回时与原图略有不同。画面上的“放大一致性误差”是在这些校正之前测得的。「最小干预 · 纯 Lanczos」（최소 개입 · 순수 Lanczos）之类的预设会把两条约束都关掉。

### 2.2 光在线性光中混合

保存在屏幕上的值（sRGB）是为配合人眼而弯曲过的值。混合两个像素的光，正确的做法不是在这个弯曲的值上，而是在实际的光量（线性光）上进行。直接在弯曲的值上插值，亮面与暗面的交界会暗沉成团。Upscaly 默认在线性光中计算，只在保存时转回 sRGB。关闭「在线性光中计算」（선형광에서 계산）复选框后，会直接在伽马空间中计算（不推荐）。

透明图片用颜色乘以 alpha 后的值（预乘）计算。并且在原图准备、分步放大的中间阶段、最终分块计算中，**alpha 也经过与颜色完全相同的运算。** 如果颜色与 alpha 被不同地滤波，之后用 alpha 去除颜色时，半透明边缘的颜色就会出错。

### 2.3 模糊与噪点在放大前、以原图分辨率处理

相机镜头和扫描仪拍下的场景会略微模糊，传感器和压缩会叠加噪点。这些瑕疵产生于原图分辨率，因此应在原图分辨率下还原。放大之后再处理时，瑕疵也一并被放大，更难也更慢。

- **模糊**用 Richardson–Lucy 反卷积反向估计。放大结果看起来比原图更清晰，原因大多来自这里。
- **噪点**以直接在图片上测得的噪声谱为基准去除。比噪声大的成分（轮廓·纹理）保留，只削弱与噪声无法区分的成分。
- **JPEG 痕迹**读取文件的量化表来去除。此时亮度的 DCT 系数会被拉回，不超出原文件的量化区间，因此不会抹掉文件中记录的细节。这一保证只适用于该投影阶段的亮度。色度分量，以及其后的块缓解、降噪、反卷积、放大、锐化，都可能把系数移出区间。

### 2.4 线条要重新绘制

两种颜色界限分明的图形（标志·线稿·文字）中，原图的锯齿本身容易被当作“正确答案”保留下来。Upscaly 找到这类边界，在放大后的分辨率上重新绘制为 1 像素宽的轮廓。把平滑插值结果的 50% 等值线视为轮廓位置，按到它的距离立起截面（符号距离方式）。方向平滑把轮廓的形状拉直，重绘把截面立起，两者一起使用，就能得到既无锯齿又不晕开的线条。

### 2.5 编造的纹理不是纹理，而是颗粒

放大无法产生比原图像素间隔更细的图案。因此放大后的照片中，皮肤纹理、布料纱线、叶脉会消失，看起来像蜡一样光滑。消失的纹理的**量**是可以推测的。因为自然图像的空间频率每翻一倍，所含能量大致相同（功率谱约为 $`1/f^2`$）。用在原图细频段测得的纹理强度，可以估算缺失的倍频程中原本有多少纹理。

但纹理的**位置和形状**在原图中并不存在。Upscaly 叠加的是与该量相匹配的噪声，也就是类似胶片颗粒的细腻纹理。由于它与真值位置不一致，能量越接近真值，与原图的差异（PSNR）越大，看起来也越像噪点而不像纹理。因此纹理恢复是「自动」不会触碰的可选功能，并建议以低强度用于人物、皮肤、布料等光滑的表面。要把纹理的形状也画得逼真，需要生成模型（神经网络）（[11. 局限](#11-局限)）。

### 2.6 用细微噪声掩盖 8 位的阶梯

处理以浮点数进行，但通常保存的 8 位 PNG 只用 256 级记录亮度。把平滑的天空放大 8 倍，原图中每隔几个像素变化一级的亮度，就会变成数十像素宽的色带。在取整之前混入小于半级的噪声（抖动），色带边界就会散成细腻的纹理而看不出来。噪声是只由画面坐标决定的图案，因此每个分块都相同，并且三个通道使用同一噪声，灰色仍保持灰色。纯色区域这类本来就恰好落在整数上的值不会改变。

### 2.7 手机照片的色彩比 sRGB 更广

如今的手机照片常以比 sRGB 更广的 Display P3 色域拍摄。用普通画布（sRGB）读取时，浏览器会把 sRGB 之外鲜艳的红色、绿色压进 sRGB 内，放大结果就会比原图暗淡。Upscaly 读取原文件的色彩配置文件，若是广色域就用 P3 画布读取，结果也附上 P3 配置文件保存。Display P3 与 sRGB 使用相同的传递曲线，因此线性光计算不变，只有原色不同。

### 2.8 每张图的答案都不同

适合照片的设置会毁掉线稿，适合线稿的设置会毁掉照片。原图一致性对照片有益，但在两种颜色界限分明的线稿中，会把原图的锯齿当作正确答案复原出来。因此「自动」先判断图片类型（9 类分类器），从适合该类型的预设出发，再用在这张图上测得的值调整细节。大倍率放大时，使用在 1.52 万亿种设置空间中搜索得到的值（[9.4](#94-大倍率复原搜索)）。

### 2.9 准确与观感是不同的目标

最接近原图的结果（PSNR 最高的结果）并不是看起来最清晰的结果。放大甚至会把原图分辨率能容纳的轮廓也稍微变钝（相对真值的轮廓斜率 0.81 倍），并削弱原图几个像素尺度的明暗差（0.94 倍）。眼睛会把这两者感知为清晰度。因此把目标分成两种。「准确」就是此前的复原，「观感」在其基础上把这两项恢复到真值的水平。它不制造新的极值，所以不会出现白边，也不会画进原图没有的纹理。代价是与原图相比的数值略有下降（[4.21](#421-观感锐度)、[9.10](#910-观感锐度)）。

## 3. 工作方式

### 3.1 整体流程

```
文件 ─▶ 解码(EXIF 方向) ─▶ 色彩配置文件(广色域则用 P3 画布) ─▶ JPEG 文件头(量化表·采样) ─▶ 主体框
                                              │
              「自动」: 分析图像 ─▶ 9 类分类 ─▶ 预设 + 测量调整 ─▶ 大倍率复原搜索值 / 方向平滑测量 / 分步放大测量
                                              │
原图准备(原图分辨率) : 线性光平面(预乘) ─▶ 色彩处理 ─▶ DCT 精细复原 ─▶ 块缓解 ─▶ 降噪 ─▶ RL 反卷积 ─▶ 分步放大中间阶段
                                              │
分块计算(worker 池)  : 插值 ─▶ 单元范围 ─▶ 一致性↔单元范围交替投影 ─▶ 统计 ─▶ 反锐化 ─▶ 方向平滑 ─▶ 轮廓重绘 ─▶ (纹理) ─▶ 解除预乘 ─▶ 编码(8 位抖动)
                                              │
                         分块缓存(LRU) ─▶ 屏幕 / 按分块行保存 PNG(8·16 位, sRGB 或 P3)
```

### 3.2 读取

文件先用 `createImageBitmap`（应用 EXIF 方向）解码，失败时依次退回到 `<img>` 的 Blob URL，再到 Data URL。广色域文件（2.7 节）在解码前判别，优先走 `<img>` 路径（Blob URL，失败则 Data URL），两者都不行时才退回 `createImageBitmap`。因为 `createImageBitmap` 的默认色彩转换因浏览器而异，可能截断为 sRGB。大文件有时浏览器确实要花几十秒，因此超时时间按文件大小成比例设定（45 秒 + 每 MB 9 秒，最长 5 分钟）。无论走哪条路径，都不会留下一直等待不结束的情况。

如果是 JPEG，只读取文件头，获取量化表、采样比（4:2:0 等）、质量估计值和 EXIF 方向。不解码熵编码数据。解码器是否应用了 EXIF 方向，通过解码结果的宽高来确认，并按显示方向重新对齐 JPEG 8×8 网格。

还会在文件中查找色彩配置文件（沿着片段·块·盒的头部只读取需要的部分，因此即使前面有大块元数据或图像盒也能找到）。JPEG 查 APP2 `ICC_PROFILE` 片段，PNG 查 cICP·iCCP·sRGB 块（与出现顺序无关，按此优先级），WebP 查 ICCP 块，AVIF·HEIF 查与主图像关联的 colr 盒。若色域比 sRGB 更广，就把原图画布建为 `display-p3` 并在其上绘制，在信息栏中标注“Display P3”。浏览器不支持 P3 画布时，按以前的方式以 sRGB 读取。

对每张图，把原图缩小到 360px 左右，寻找显著度（与平均色的距离）团块，生成主体框。可以用画面上的「主体」（피사체）按钮查看。

### 3.3 原图准备（`prepareSource`）

在原图分辨率下完成的校正全部在这里进行。结果连同设置的键最多缓存最近两份，即使放大结果被挤出缓存，只要设置相同就能复用。

1. **线性光平面。** 用 256 项的表把 8 位 sRGB 转为线性光，若有 alpha 则把颜色乘以 alpha。
2. **色彩处理。** 仅当白平衡强度不为 0 时进行（默认 0）。
3. **DCT 精细复原。** 用噪声谱和 JPEG 量化表整理原图。按条带分给 worker 处理，并把 DCT 网格固定在全局坐标上，因此条带边界没有接缝。
4. **JPEG 块缓解。** 仅当 8 的倍数位置上的台阶小于周围变化时才抚平。
5. **降噪。** 只在亮度相近的邻居之间求平均（双边滤波）。alpha 也用同样的权重求平均。
6. **RL 反卷积。** alpha 也经过同样的次数。
7. **分步放大的中间阶段。** 把大倍率分成两步以上时，最后一步之前的放大在这里完成。DCCI 在中间阶段也使用方向插值，像素画在每一步都复原轮廓。alpha 经过与颜色相同的方向权重、单元范围和步间锐化。最终阶段的单元范围与一致性基准不是中间图像，而是**原图**。

### 3.4 分块计算（`renderTile`）

结果分成块（按倍率 512~1024px，整数倍率时为倍率的倍数）计算。每个块接收所需的原图片段（插值支撑范围 + 一致性余量 + 方向场·轮廓模型余量）独立计算，因此无论先算哪个块，结果都一样。

1. **插值。** 若是 DCCI，一次放大所有通道（`dcciStageMulti`）。方向权重只在引导平面（伽马亮度 + alpha 轮廓项）上计算一次，由各通道共享。然后用 Catmull-Rom 对齐到精确倍率。
2. **单元范围限制。** 用原图 2×2 单元各通道的最小值·最大值截断。
3. **一致性校正与单元范围的交替投影。** 交替投影两次（单元范围关闭时只做一次一致性校正）。每一遍都在比结果区域宽 7 像素的区域上求解，因此任何一遍都不会读取系数网格之外的内容。
4. **统计。** 为了在画面上显示结果缩回后与原图的差异（放大一致性误差），用校正前的值测量。
5. **反锐化。** 用与局部振幅成比例的拐点限幅器抑制光晕。
6. **方向平滑。** 只沿用原图结构张量求出的切线方向求平均。
7. **轮廓重绘。** 用符号距离重新绘制 1 像素宽的轮廓。
8. **观感锐度。** 仅当目标为「观感」时，在亮度上提高轮廓斜率与局部对比度。不会超出周围的亮度范围（[4.21](#421-观感锐度)）。
9. **纹理恢复。** 仅在开启时，按在原图上测得的纹理强度，给结果补上缺失的细腻纹理。分步放大时在原图而非中间图像上测量。对原样复制原图的最近邻核和保持调色板的像素画核不使用，滑块也会关闭。
10. **解除预乘与编码。** 转为屏幕用的 8 位、保存用的 8·16 位。8 位在开启抖动（默认）时，会在取整前混入由坐标决定的细微噪声。屏幕和 8 位保存使用同一份分块，因此所见即所存。

worker 池启动核心数 − 1 个（最多 8 个），若 5 秒内无响应，就在主线程用同一引擎计算。引擎（`ENGINE_FACTORY`）是纯计算函数的集合，因此同一段代码也以 Blob URL worker 的形式加载。

### 3.5 分步放大

把大倍率分成多次放大的方式。可从先 2 倍、先大倍率、均衡（小的先·大的先）、均等（√×√）、三步中选择。步与步之间可以加锐化。指示灯把当前图片的中央按目标倍率用光的面积平均缩小，再把一次放大的结果与按当前方式分步放大的结果分别和原图比较（PSNR），告诉你当前复选框状态是否是更好的一方。结果按图片·设置记忆。

### 3.6 自动

1. **分析。** 长边超过 1024 时，先用 2×2 平均逐次减半，再用整数倍盒式平均缩到 512 以下，在这个分析图像上测量 27 种特征。包括结构张量（纹理比例、轴对齐边缘）、强边缘与轮廓线、文字行周期、长直线、色彩·亮度构成、原图分辨率片段的 8×8 块平面残差、最近邻放大网格、原图颜色数、网点等。
2. **分类。** 用多项逻辑回归从照片·插画·绘画·漫画·线稿·文档·UI·标志·像素画中选出一类。像素画不靠概率，而是靠结构（最近邻整数倍网格，或 1× 下的少量调色板）确定。推动判定的依据（各特征对第 1 名与第 2 名 logit 差的贡献）会显示在画面上。
3. **预设与测量调整。** 从适合该类型的预设出发，用噪声（平坦区拉普拉斯中位数）、边缘宽度、8px 网格对比度、JPEG 质量，调整反卷积迭代次数·σ、JPEG 复原、块缓解等。
4. **大倍率复原搜索值。** 若类型和倍率符合验证条件，直接使用搜索得到的设置（`AUTO_BIG`）。照片·线稿·UI·绘画为 2× 以上，文档为 4× 以上。标志和漫画仅在 2× 以上且为 JPEG 文件时使用，因为在干净输入上没有通过验证（[9.4](#94-大倍率复原搜索)）。插画不使用。
5. **逐图测量。** 不使用搜索值时，对图画（照片·像素画除外）在该图上测量并选择方向平滑的强度（`autoAA`），然后测量分步放大的所有方式，调整为最好的一种（`autoStage`）。

自动请求带有编号，迟完成的先前测量不会应用到新打开的图片上。自动之后改变倍率，会提示你重新点击。

### 3.7 自动倍率

在 3~8× 中选出渲染**有保证**的最大倍率。按下倍率栏中的「自动」，会立即移到当前设置下有保证的最大倍率。“保证”是指整个处理过程的最大内存在内存预算的 80% 以内、剩余部分大于最小缓存、结果在保存上限之内。保存期间积累在内存中的压缩 PNG（在 47 张数据上测得的最大压缩率外加 10% 余量），以及缓存中残留的前一张图片的已准备原图，也会计入。每个倍率下「自动」选择的设置（预设·大倍率复原搜索值·分步放大）不同，预算也不同，因此「自动」从大倍率开始，实际应用该倍率的设置，选出第一个有保证的倍率。在这张照片上测量并决定分步放大时，也只在有保证的方式中选择。选定后，会真的把分块缓存的上限降到该值。若连 3× 也无法保证，就退回到比它小的倍率中有保证的最大者。

### 3.8 保存

浏览器支持 `CompressionStream('deflate')` 时，按分块行（16 位为 128 行条带）逐段压缩，拼接成 PNG 片段。8 位复用缓存中的分块，16 位按条带重新计算。不会创建容纳整个结果的大画布，但压缩后的片段会在保存完成前一直汇集在内存中，再作为一个文件输出。文件中包含色彩空间块，以及记录核与倍率的 `Software` iTXt 块（UTF-8）。色彩空间块通常是 sRGB；以 P3 读取的图片则是 cICP（原色 12 = Display P3，传递 13 = sRGB 曲线）以及含义相同的 Display P3 ICC 配置文件（iCCP）。能读 cICP 的程序使用 cICP，不能读的使用 ICC。没有流式压缩的浏览器只能保存 8 位。这时把结果汇集到一个画布上用浏览器编码器保存，若超出画布上限，就记下该设备的实际上限。在这类浏览器中选择 16 位保存会导致保存失败。

### 3.9 色彩处理

色彩处理是与放大分离的独立功能，默认值为 0。按下「色彩自动」（색 자동）后，用三种方法（平均、边缘、亮面）估计光源颜色，只按三者都认可的程度设定白平衡强度。真正的光源色偏会连亮面一起染色，三者会一起变大；而橙色的猫或晚霞这类主体固有色只会拉动平均值。插画·绘画·UI·标志·像素画的颜色被视为有意为之，不做修正。整体亮度保持不变，通道增益限制在 0.55~1.8。

## 4. 算法与公式

下文中 $`I`$ 为原图（线性光，预乘），$`U`$ 为结果，$`s_x, s_y`$ 为横向·纵向倍率。

### 4.1 色彩空间

```math
\mathrm{lin}(u) =
\begin{cases}
u / 12.92 & u \le 0.04045 \\[2pt]
\left(\dfrac{u + 0.055}{1.055}\right)^{2.4} & \text{其他}
\end{cases}
\qquad
\mathrm{srgb}(v) =
\begin{cases}
12.92\,v & v \le 0.0031308 \\[2pt]
1.055\,v^{1/2.4} - 0.055 & \text{其他}
\end{cases}
```

8 位 → 线性光使用 256 项的表，线性光 → 8 位使用 8,192 项的表（量化误差小于 1 级）。16 位编码器以 $`\sqrt{v}`$ 为轴建表，使接近黑色的陡峭区间也能控制在 1 级以内。把 8 位的 256 级转为线性光再转回，256 级全部保持不变（[9.1](#91-不变量)）。

有 alpha 时，用预乘值 $`(\alpha R, \alpha G, \alpha B, \alpha)`$ 计算，在编码之前若 $`\alpha > 10^{-7}`$ 则除以 $`\alpha`$。

### 4.2 重建核

以可分离方式（横向 → 纵向）应用，并对齐像素中心（$`u = (X + 0.5)/s - 0.5`$）。缩小时把核按倍率拉宽以防止混叠。

```math
L_a(x) = \mathrm{sinc}(x)\,\mathrm{sinc}(x/a)\ \ (|x| < a),\qquad
k_{B,C}(x) = \tfrac16
\begin{cases}
(12 - 9B - 6C)|x|^3 + (-18 + 12B + 6C)|x|^2 + (6 - 2B) & |x| < 1 \\
(-B - 6C)|x|^3 + (6B + 30C)|x|^2 + (-12B - 48C)|x| + (8B + 24C) & 1 \le |x| < 2
\end{cases}
```

Lanczos-3·4 为 $`a = 3, 4`$，Catmull-Rom 为 $`(B, C) = (0, 0.5)`$，Mitchell–Netravali 为 $`(1/3, 1/3)`$。最近邻在整数倍率下原样复制原图，因此缩回后与原图逐位相同。

### 4.3 边缘自适应 DCCI

以 Zhou 等（2012）的方向三次卷积插值为基础，每一步放大 2 倍（角对齐：输出 $`(2i, 2j)`$ = 输入 $`(i, j)`$）。

**第 1 步：2×2 单元的中心。** 在 4×4 邻域中测量两个对角方向的变化量。$`G`$ 为引导平面（伽马亮度 0~255），$`n_{\mathrm{off}}`$ 为噪声底。

```math
d_1 = \sum_{(p,q) \in \nearrow} |G_p - G_q| + n_{\mathrm{off}},\qquad
d_2 = \sum_{(p,q) \in \searrow} |G_p - G_q| + n_{\mathrm{off}}
```

每个和是沿相应对角方向相邻的 9 对。权重如下（$`T = 1.15`$）。

```math
(w_a, w_b) =
\begin{cases}
(0, 1) & 1 + d_1 > T(1 + d_2) \\
(1, 0) & 1 + d_2 > T(1 + d_1) \\
\left(\dfrac{a}{a+b}, \dfrac{b}{a+b}\right),\ a = \dfrac{1}{1 + d_1^{5}},\ b = \dfrac{1}{1 + d_2^{5}} & \text{其他}
\end{cases}
```

若 $`\nearrow`$ 方向变化大，说明轮廓沿 $`\searrow`$ 方向延伸，因此沿该方向插值。各方向的值采用三次卷积抽头 $`(-1, 9, 9, -1)/16`$。

```math
p_a = \tfrac{1}{16}\big(9(f_{12} + f_{21}) - (f_{03} + f_{30})\big),\quad
p_b = \tfrac{1}{16}\big(9(f_{11} + f_{22}) - (f_{00} + f_{33})\big),\quad
v = \mathrm{clip}\big(w_a p_a + w_b p_b,\ \min_4 f,\ \max_4 f\big)
```

最后的 `clip` 是原论文中没有的附加项。它使新值不超过最近 4 个邻点的范围，从这一步起就不会产生振铃和光晕。

**第 2 步：横向·纵向之间的像素。** 在旋转 45° 的网格上，沿横向·纵向执行同样的步骤。边界用镜像反射折回，保持偶对称。

**步数。** 使用按倍率实测后固定的表（`EDI_PLAN`）。2× 以下为 2 倍网格一步，更大时先放大到 4 倍网格（两步），再用 Catmull-Rom 对齐到精确倍率（[8. 优化](#8-优化)）。

### 4.4 单元范围限制

按输出样本 $`U(X, Y)`$ 所属原图单元 $`(i..i{+}1,\ j..j{+}1)`$ 的各通道范围截断。

```math
U(X, Y) \leftarrow \mathrm{clip}\Big(U(X, Y),\ \min_{(p,q) \in \mathrm{cell}} I_{p,q},\ \max_{(p,q) \in \mathrm{cell}} I_{p,q}\Big)
```

最近邻放大始终位于这个范围内，因此解一定存在。每个单元的最小值·最大值对每个通道平面只构建一次（`cellRange` 缓存）。

### 4.5 原图一致性校正

把结果按面积平均缩回的运算记为 $`D`$，目标是 $`D(U) = I`$。在初始估计 $`U_0`$ 上，加上把原图分辨率的系数 $`c`$ 用双线性插值 $`P`$ 展开后的量。

```math
U = U_0 + P(c),\qquad D(U_0 + P c) = I \;\Longrightarrow\; K c = I - D(U_0),\quad K = D P
```

$`D`$ 和 $`P`$ 都可按轴分离，因此 $`K = K_x \otimes K_y`$，各轴的 $`K`$ 为三对角矩阵。于是用 Thomas 算法在原图分辨率下精确求解 $`c`$。各轴的系数由输出像素在原图上的覆盖区（含分数重叠）构造。逆矩阵的衰减约为每像素 0.17 倍，7 像素之外的影响不超过 $`0.17^7 \approx 4 \times 10^{-6}`$。因此每个分块留 7 像素余量求解，与一次性求解整体的结果相同。

### 4.6 交替投影

一致性条件 $`\{U : D U = I\}`$ 是仿射集，单元范围 $`\{U : m \le U \le M\}`$ 是盒集。两者都是凸集，因此交替投影会向交集靠近。

```math
U^{(k+1)} = \Pi_{\mathrm{box}}\Big(\Pi_{\mathrm{affine}}\big(U^{(k)}\big)\Big),\qquad k = 0, 1
```

Upscaly 投影两次（单元范围关闭时只做一次一致性投影）。一致性投影不是严格的正交投影，而是沿 $`P`$ 方向的校正；最后一次投影是单元范围，因此“不产生新极值”的承诺始终成立。

### 4.7 Richardson–Lucy 反卷积

把模糊视为标准差 $`\sigma`$ 的高斯 $`h`$，由观测 $`o`$ 以乘法形式更新估计 $`e`$。

```math
e^{(t+1)} = e^{(t)} \cdot \left( h \ast \mathrm{clip}\!\left(\frac{o}{h \ast e^{(t)}}\right) \right)
```

比值会被截断以免发散。乘法更新保持常数倍关系，因此对预乘颜色和 alpha 应用相同次数，在同色区域中颜色/alpha 的比值保持不变。

### 4.8 降噪（双边滤波）

分横向·纵向应用，亮度差权重做成 1,025 项的表，避免调用指数函数。

```math
\hat I_p = \frac{\sum_q w_s(\|p - q\|)\, w_r(|G_p - G_q|)\, I_q}{\sum_q w_s(\|p - q\|)\, w_r(|G_p - G_q|)}
```

$`G`$ 为伽马近似亮度。alpha 平面也用同样的权重求平均。

### 4.9 DCT 精细复原

**噪声模型。** 对每个通道（Y、Cb、Cr），用 8×8 DCT 各频率的方差 $`S_c[k]`$ 和按亮度区间的增益 $`g_c(I)`$ 表示噪声。

1. 反复挑选高频（$`u + v \ge 6`$）能量小的块，用各频率的平均得到谱形状。纹理的能量集中在低频，因此选择和增益只用高频。
2. 亮度用 PCA 噪声底设上限。即弱纹理块的 63 维协方差中最小 3 个特征值的平均。纹理只分布在少数几个方向上，而噪声分布在全部 63 个方向上，因此可以避免把纹理误认为噪声而抹掉。样本数有限的影响用 Marchenko–Pastur 下界 $`\gamma = \sqrt{n / n_{\mathrm{sel}}}`$ 校正。
3. 不确定时偏向低估（保护细节）一侧。只剩 8 位量化噪声（$`1/12`$）的干净图像实际上视为 0。

**去噪。** 结构为滑动 8×8 DCT 上去掉 BM3D 块匹配后的两步。由块平均亮度 $`\bar I`$，把各系数的噪声方差设为 $`\sigma_k^2 = S[k]\, g(\bar I)\, \lambda^2`$（$`\lambda`$ 为强度）。$`F_k`$ 为输入块的系数，$`B_k`$ 为第 1 步结果图像中同一块的系数。

```math
\text{第 1 步：} \hat F_k = F_k \cdot \mathbf{1}\big[\,F_k^2 \ge \tau^2 \sigma_k^2\,\big],\qquad
\text{第 2 步：} \tilde F_k = F_k \cdot W_k,\quad W_k = \frac{B_k^2}{B_k^2 + \sigma_k^2}
```

重叠的块用 Kaiser 窗（$`\beta = 2`$），并像 BM3D 那样对每个块在第 1 步用 $`1/(1 + n_{\mathrm{nz}})`$、第 2 步用 $`1/\sum_k W_k^2 \sigma_k^2`$ 的权重合并（$`n_{\mathrm{nz}}`$ 为保留的系数数）。块网格固定在全局坐标上，因此没有分块接缝。

**JPEG 量化区间投影（QCS）。** 若是 JPEG，用文件的量化表 $`q_k`$ 把量化噪声的方差加入噪声模型，并把亮度的 DCT 系数拉回到观测量化值周围的区间。由于不解码熵编码数据，观测系数通过把解码后的图像按文件的 8×8 网格做 DCT 得到 $`G_k`$，再按量化表取整获得。

```math
c_k = q_k \cdot \mathrm{round}\!\left(\frac{G_k - \ell_k}{q_k}\right) + \ell_k,\qquad
F_k \leftarrow \mathrm{clip}\big(F_k,\ c_k - \Delta_k,\ c_k + \Delta_k\big),\qquad
\Delta_k = \tfrac12 \rho_k q_k + \delta_k
```

$`\ell_k`$ 是只存在于 DC 的 128 电平偏移。以非零值记录的交流系数中去掉最低频后的部分（$`u + v \ge 2`$，编码器留下的真实纹理）用 $`\rho_k = \rho`$（默认 0.5）收窄区间以保护纹理强度；零系数·DC·最低频（块效应与振铃的根源）用 $`\rho_k = 1`$ 使用整个区间来消除伪影。$`\delta_k = 2.5\sigma_k`$（仅交流）是为带噪压缩的情况留出的去除噪声的余地。（去噪 → 投影）重复两次，第二次把量化噪声方差减半使用。

**色度。** 色度平面也用同样方式去噪后，再用引导滤波把 4:2:0 等色度采样造成的模糊颜色边界对齐到复原后的亮度轮廓（局部地，色度 $`= a \cdot`$ 亮度 $`+ b`$）。

**细节找回。** 若不是 JPEG，当被去除部分的局部能量 $`v`$ 超过噪声模型能解释的量 $`\tau \sigma^2`$ 时，按超出的比例还回去。

```math
\hat I \leftarrow \hat I + \mu \left(1 - \frac{\tau \sigma^2}{v}\right)(I - \hat I)\qquad (v > \tau \sigma^2)
```

### 4.10 反锐化掩模（光晕抑制）

求出细节 $`d = I - G_\sigma \ast I`$ 和局部振幅 $`A = G_{2\sigma} \ast |d|`$ 后，按以下顺序处理。

```math
d \leftarrow d \cdot \frac{d^2}{d^2 + t^2}\ \ (\text{平坦区保护}),\qquad
d \leftarrow a\, d,\qquad
d \leftarrow \frac{d}{1 + |d| / (o A + 10^{-4})}\ \ (\text{光晕容许度})
```

$`a`$ 为强度，$`t`$ 为平坦区保护，$`o`$ 为光晕容许度。最后一式是拐点柔和的限幅器，在大轮廓处过冲不会超过局部振幅的 $`o`$ 倍。半径 0 时按倍率自动设定。

### 4.11 方向平滑（去锯齿）

在原图上求结构张量 $`J = G \ast (\nabla Y \nabla Y^{\top})`$，把较小特征值的特征向量作为切线方向 $`\mathbf t`$，用较大特征值 $`\lambda_1`$ 确定强度 $`w = \min(1, \lambda_1 / 0.0016)`$。在放大结果上只沿切线方向求平均。

```math
\bar U = 0.34\,U(\mathbf x) + 0.22\,\big(U(\mathbf x + \ell \mathbf t) + U(\mathbf x - \ell \mathbf t)\big) + 0.11\,\big(U(\mathbf x + 2\ell \mathbf t) + U(\mathbf x - 2\ell \mathbf t)\big),\qquad
U \leftarrow U + w\,\kappa\,(\bar U - U)
```

锯齿的周期等于倍率，因此步长 $`\ell`$ 设为倍率的 0.8 倍（1~8）。一次不够，按强度成比例重复 1~4 次。重复越多，抖动按乘法减小，而过渡宽度不变。方向场在全局坐标上求得，因此在分块边界上也得到相同的值。

### 4.12 轮廓重绘（符号距离）

若原图 5×5 窗口中的像素落在暗色与亮色 $`(\mathrm{lo}, \mathrm{hi})`$ 之间的线段上，且变化发生在 1~2 像素之内，就视为轮廓。把放大结果换算成线段上的位置 $`t \in [0, 1]`$，用到 0.5 等值线的符号距离重新绘制 1 像素宽的斜坡。

```math
t' = \mathrm{clip}\!\left(0.5 + \frac{t - 0.5}{|\nabla t|},\ 0,\ 1\right),\qquad
U \leftarrow U + \gamma\,w_{\mathrm{fit}}\big(\mathrm{lo} + t'(\mathrm{hi} - \mathrm{lo}) - U\big)
```

$`|\nabla t|`$ 为每个输出像素的梯度。实际计算以把 $`U + (t' - t)(\mathrm{hi} - \mathrm{lo})`$ 截断到 $`[\mathrm{lo}, \mathrm{hi}]`$ 后的值为目标，混合权重 $`\gamma\,w_{\mathrm{fit}}`$ 是在原图分辨率下由重绘强度和拟合度（中央 3×3 偏离线段的程度）构造的权重经双线性展开后的值。50% 等值线重绘只在宽度超过 1 像素的线条上保持面积（浓度），因此用横跨线条的积分浓度测得宽度在 1 像素左右的细线不做处理，以防止线条扭曲。

### 4.13 像素画轮廓复原

形状由 DCCI 场决定（45°·2:1 的阶梯变成直线），颜色固定为各子样本所属原图 2×2 单元的 4 个原色中最接近场值的颜色。对每个输出像素平均 4×4 个子样本，只对轮廓做抗锯齿，因此新颜色只出现在轮廓边界上。单元内 4 色相同时走快速路径跳过。

### 4.14 白平衡共识

「色彩自动」在分析图像（线性光）中去掉饱和（0.95 以上）和近黑（0.004 以下）像素，用三个估计器求光源颜色。

```math
e^{\mathrm{sog}}_c = \Big(\tfrac1n \sum f_c^{6}\Big)^{1/6},\qquad
e^{\mathrm{ge}}_c = \Big(\tfrac1n \sum |\nabla (G \ast f_c)|^{6}\Big)^{1/6},\qquad
e^{\mathrm{wp}}_c = Q_{0.99}(f_c)
```

分别是 Shades of Gray（平均）、Gray Edge（边缘）、White Patch（亮面，第 99 百分位）。$`G`$ 为 $`[1,4,6,4,1]/16`$ 平滑。由各估计与中性 $`(1,1,1)`$ 所成的角度 $`\theta`$ 确定强度 $`a`$。

```math
a =
\begin{cases}
0 & \theta_{\min} < 3^\circ \ \text{或}\ \theta_{\min} > 28^\circ \ \text{或}\ \theta_{\max} - \theta_{\min} > 10^\circ \\[2pt]
\min\!\big(1,\ \theta_{\min} / \theta_{\mathrm{sog}}\big) \cdot h,\quad h = \begin{cases} \tfrac12 & \theta_{\mathrm{wp}} < 0.8\,\theta_{\mathrm{sog}} \\ 1 & \text{其他} \end{cases} & \text{其他}
\end{cases}
```

三个条件依次对应：没有偏色、难以视为光照的场景固有色、混合光照。若亮面比平均染色更少，就认为是主体颜色拉动了平均值，只校正一半。强度以 0.05 为单位取整。处理时，在去掉半透明（alpha 小于 0.5）·饱和·近黑像素后的最多 15 万像素上求通道增益，归一化以保持整体亮度（$`0.2126R + 0.7152G + 0.0722B`$），按 $`1 + (g - 1)a`$ 混合后截断到 0.55~1.8。

### 4.15 9 类分类器

对用训练均值·标准差标准化 27 维特征 $`\mathbf x`$ 得到的 $`\mathbf z`$ 使用多项逻辑回归。

```math
P(k \mid \mathbf x) = \frac{\exp(\mathbf w_k^{\top} \mathbf z + b_k)}{\sum_j \exp(\mathbf w_j^{\top} \mathbf z + b_j)}
```

各类样本数不同，因此设置类别均衡权重，用 L-BFGS-B 最小化带 L2 正则的交叉熵。受 JPEG 质量影响的特征（单色块、无噪块、噪声底、平滑块）乘以质量可信度 $`r = \mathrm{clip}((q - 50)/40,\ 0.05,\ 1)`$。判定依据是各特征对第 1 名 $`k_1`$ 与第 2 名 $`k_2`$ logit 差的贡献 $`z_j (w_{k_1 j} - w_{k_2 j})`$，按大小排序。

### 4.16 渲染预算

由倍率 $`L`$、原图像素数 $`n_0`$、结果像素数 $`N`$，各阶段的最大内存（字节）如下估算。

```math
\begin{aligned}
M_{\mathrm{prep}} &= \max\big(32\,n_0,\ \ 4 c\, n_0 + 32\, n_0 s_k^2\big) && \text{原图准备、分步放大中间阶段} \\
M_{\mathrm{fixed}} &= M_{\mathrm{other}} + M_{\mathrm{src}}^{1} + M_{\mathrm{keep}} + n_w (T + 64 + 2t + 2p)^2 (48 + 24[t > 0] + 32[p > 0]) + 1.5\,W \max(4T, 1024) + 1.1\,\rho\, c\, b\, N && \text{其他原图·已准备原图、保留平面、worker 分块、保存条带、压缩 PNG} \\
\text{保证} &\iff M_{\mathrm{other}} + M_{\mathrm{src}}^{2} + M_{\mathrm{prep}} \le 0.8B \ \wedge\ 0.8B - M_{\mathrm{fixed}} \ge 4 \min\big(N, \max(4 \times 10^6, 2WT)\big)

```

$`c`$ 为通道数，$`s_k`$ 为分步放大的中间倍率，$`n_w`$ 为 worker 数，$`T`$ 为分块尺寸，$`t`$ 为纹理恢复的结果余量（关闭时为 0），$`W`$ 为结果宽度，$`B`$ 为内存预算。$`M_{\mathrm{src}}^{2}`$ 为缓存中残留的其他已准备原图的全部（新准备期间两者都在），$`M_{\mathrm{src}}^{1}`$ 为其中最近的一份（放入新的之后只剩一份）。$`b`$ 为每通道字节数（8 位为 1，16 位为 2），$`\rho`$ 为保存 PNG 压缩率的最大值。它是把 `data/big` 的 47 张图放大 1.1·1.25·1.5·2·3·4×，用应用的编码器测得的。2× 以上同时测量只用预设的情况和连「自动」的大倍率复原搜索值（`AUTO_BIG`）也用上的情况，取较大者；2× 以下不使用搜索值，因此只有预设（`research/budget/png_ratio.js`、`research/results/png_ratio.json`）。使用夹住结果倍率的两个测量倍率中较大的值（4× 以上用 4× 的值）。面积倍率 1.25× 换算成宽·高也是 1.12×，在测量范围内；1.1× 以下按压缩前大小计算。 $`p`$ 为「观感」的结果边距（两次模糊及邻域最小·最大值，「准确」时为 0）。压缩率也在「观感」（强度最高 150%，纹理关·开）下测量，取两种目标中较大的值（`research/results/png_ratio_pop.json`）。

### 4.17 8 位抖动

在取整前的连续 sRGB 值 $`s = 255\,\mathrm{srgb}(v)`$ 上，加上只由结果坐标 $`(X, Y)`$ 决定的交错梯度噪声（IGN，Jimenez 2014）。

```math
\nu(X, Y) = \mathrm{frac}\!\big(52.9829189 \cdot \mathrm{frac}(0.06711056\,X + 0.00583715\,Y)\big) - \tfrac12,\qquad
b = \big\lfloor s + \tfrac12 + 0.98\,\nu \big\rfloor
```

振幅为 ±0.49 级，因此 $`|s - k| < 0.01`$ 的值（精确码值 $`k`$）仍然得到 $`k`$。连续 sRGB 值通过对 16 位编码器的 $`\sqrt v`$ 轴表插值得到，插值误差最大 0.002 级。三个通道使用同一个 $`\nu`$，alpha 不做抖动。

### 4.18 纹理恢复

在原图（线性光，预乘）的伽马近似亮度 $`Y = \sqrt{\ell}`$、$`\ell = 0.2126R + 0.7152G + 0.0722B`$ 上，测量第二细频段的局部强度与轮廓遮蔽。

```math
a = \mathrm{erode}_{5\times5}\!\left(\sqrt{G_{1.5} \ast (G_1 \ast Y - G_2 \ast Y)^2}\right),\qquad
m = \big(1 - c^2\big)^2,\quad c = \frac{\sqrt{(J_{xx} - J_{yy})^2 + 4J_{xy}^2}}{J_{xx} + J_{yy}}
```

$`G_\sigma`$ 为高斯，$`J = G_{1.5} \ast (\nabla Y \nabla Y^{\top})`$ 为结构张量，$`c`$ 为方向一致度。5×5 最小值（腐蚀）会抹去轮廓、细线、角点这类宽度窄的强结构的强度，只留下大面积分布的纹理。$`m`$ 在沿单一方向延伸的轮廓上接近 0。

在结果分辨率（倍率 $`L`$）下，生成只保留原图奈奎斯特频率以上频段的单位方差噪声。$`h(X,Y,s)`$ 为把整数哈希映射到 [0, 1) 的值。

```math
n = \sqrt3\Big(\textstyle\sum_{s=1}^{4} h(X, Y, s) - 2\Big),\qquad
\eta = \frac{n - G_{0.375L} \ast n}{\sqrt{1 - 2k_0^2 + (\sum_i k_i^2)^2}}
```

$`k_i`$ 为一维高斯核，分母使这个差分的方差恰好为 1。$`\sigma = 0.375L`$ 是在原图奈奎斯特频率处响应减半的值。用目标方差和结果中已有的同频段方差，只补上缺失的部分。

```math
T = \big(\alpha\, C\, \sqrt{\log_2 L}\; a\, m\big)^2,\qquad
E = G_{0.5L} \ast \big(Y_U - G_{0.375L} \ast Y_U\big)^2,\qquad
\Delta = \mathrm{clip}\!\big(\sqrt{\max(0, T - E)}\;\eta,\ \pm 0.4\,Y_U\big)
```

$`\alpha`$ 为强度滑块，$`C = 6.256`$ 为通过测量确定的常数（[9.8](#98-纹理恢复)），$`Y_U`$ 为结果的伽马近似亮度。最后对三个通道（预乘）乘以同一比例 $`f = \big((Y_U + \Delta)/Y_U\big)^2`$，使色相和 alpha 保持不变。提亮时（$`f > 1`$）按 $`f \le \max\!\big(1,\ \min(1, A) / \max(R, G, B)\big)`$ 缩小，使最大的通道不超过上限（alpha，不透明时为 1）。否则在明亮、高饱和的颜色中只有一个通道被截断，色相就会改变（例：250·127·73 变成 255·130·76，v1.1.1 已修复）。噪声、原图统计、结果能量窗口全部按全局坐标确定，并相应多计算余量，因此结果与分块无关。

### 4.19 色域判别与 Display P3 配置文件

把 ICC 配置文件的原色矩阵 $`(\mathbf r, \mathbf g, \mathbf b)`$（D50 基准的 XYZ）与 sRGB 的值比较，只要有一个分量相差超过 0.02 就视为广色域。没有矩阵的 LUT 配置文件看描述字符串（P3、Adobe、2020、ProPhoto）。PNG 的 cICP 和 AVIF 的 nclx，原色编号不是 1（BT.709 = sRGB）或 2（未指定）时视为广色域。AVIF·HEIF 读取 `meta` 盒中的 `pitm`（主项）以及 `iprp` 里的 `ipma`（项 ↔ 属性编号）·`ipco`（属性），只看与主图像关联的 `colr`。即使缩略图或辅助图像的 `colr` 在前，也以主图像为准。无法读取这一结构时，使用第一个出现的 `colr`。

保存时附加的 Display P3 配置文件由应用自己生成（ICC v4.3，532 字节）。原色由 P3 的色度坐标 (0.680, 0.320)、(0.265, 0.690)、(0.150, 0.060) 和 D65 白点求出 RGB→XYZ 矩阵，再用 Bradford 变换对齐到 D50。

```math
\mathbf r = (0.515119,\ 0.241189,\ -0.001050),\quad
\mathbf g = (0.291978,\ 0.692244,\ 0.041879),\quad
\mathbf b = (0.157103,\ 0.066567,\ 0.784071)
```

曲线是与 sRGB 相同的参数曲线（类型 3：$`\gamma = 2.4`$、$`a = 1/1.055`$、$`b = 0.055/1.055`$、$`c = 1/12.92`$、$`d = 0.04045`$）。这些值与 Apple Display P3 配置文件的原色在 $`10^{-5}`$ 以内一致。

### 4.20 测量指标

```math
\mathrm{PSNR} = 10 \log_{10} \frac{255^2}{\frac{1}{3n}\sum (U - I_{\mathrm{gt}})^2},\qquad
E_{\mathrm{dir}} = \frac{\sum_p m_p\, \arccos\!\big(|\hat{\mathbf g}^{U}_p \cdot \hat{\mathbf g}^{\mathrm{gt}}_p|\big)}{\sum_p m_p}\quad (m_p \ge 80)
```

$`E_{\mathrm{dir}}`$ 为边界方向误差。在原图的强边界（Sobel 幅值 80 以上，约 20 级落差）上，把结果与原图梯度方向的偏差角按边界强度加权平均。出现锯齿时，梯度方向会偏向坐标轴，误差变大。SSIM 使用 Wang 等（2004）的定义。

### 4.21 观感锐度

在「观感」模式中，向结果亮度 $`Y`$（线性光时为 $`\sqrt{\ell}`$，伽马值时为 $`\ell`$；$`\ell`$ 是把通道截到 0~上限后的亮度）加上两个频带。$`L`$ 为倍率，$`G_\sigma`$ 为高斯（三次盒式近似），$`a`$ 为观感强度。

```math
d_1 = Y - G_{0.5L}Y,\qquad d_2 = G_{0.5L}Y - G_{2L}Y,\qquad
\tilde d = d\,\frac{d^2}{d^2+\tau^2}\quad(\tau = 0.004)
```

```math
\Delta = a\Big(k_1\,\tilde d_1 + k_2\,\frac{\tilde d_2}{1+|\tilde d_2|/c_2}\Big),\qquad
Y' = Y + \Delta\,\frac{h}{h+|\Delta|},\qquad
h = \begin{cases}\max_{\mathcal N}Y - Y & \Delta>0\\ Y-\min_{\mathcal N}Y & \Delta\le 0\end{cases}
```

$`d_1`$ 是原图奈奎斯特附近的轮廓斜率，$`d_2`$ 是原图 1~4 像素尺度的局部对比度。$`\tilde d`$ 是与反锐化掩模同形的阈值，噪点和 JPEG 痕迹这类小振幅几乎不被提升。局部对比度振幅越大提升越少（$`c_2 = 0.05`$），已经清楚的明暗保持原样，被埋没的明暗得以显现。$`\mathcal N`$ 是半径 $`\mathrm{round}(0.75L)`$ 的正方形邻域（仅图内），$`h`$ 是到邻域最小值或最大值的余量。$`\Delta\,h/(h+|\Delta|)`$ 只会平滑地接近余量而不会越过，因此不会产生新的极值（光晕）；也不会贴住边界，所以面不会结块（色调分离）。最初的做法是按邻域范围硬截，结果面结块、看起来像油画，因此改掉了。改变后的亮度以比例 $`s = Y'/Y`$（线性光时为 $`s^2`$）同等地乘到预乘的三个颜色通道上，因此色相、灰度和透明度保持不变；变亮时会缩小比例，使最大的通道不超过上限（与纹理恢复相同的处理）。 有透明度时，在解除预乘后的颜色上测量亮度，模糊采用按不透明度加权的平均，邻域最小·最大值中排除几乎透明的像素（透明度低于 2%）。因此颜色相同、只有不透明度变化的边界不会产生描边。

$`k_1 = 0.5`$、$`k_2 = 1.5`$ 是在探索用图像上选出的值。在 22 张 × 3 种条件（4× 干净、4× 劣化、8× 劣化，共 66 例）上测量 $`k_1 \in \{0.5, 1, 2, 3\}`$ × $`k_2 \in \{0, 0.5, 1, 1.5\}`$ 共 16 种组合，比较相对真值的轮廓斜率 $`A`$ 与局部对比度 $`C`$ 的对数误差 $`|\ln A| + |\ln C|`$ 的中位数。$`A`$ 是把两者都用 $`\sigma = 0.5L`$ 模糊后、在真值轮廓（斜率前 10%）处测得的斜率之比，$`C`$ 是 $`G_{0.5L}-G_{2L}`$ 频带的 RMS 之比。16 种都比「准确」（0.418）误差小（0.343~0.410），从中选了光晕和平坦区噪点增加最少的一种（误差 0.357，光晕 +0.20 级，平坦区噪点 ×1.14，SSIM +0.004）。结果在 `research/results/pop_grid.json`。

## 6. 体系结构

### 文件与运行环境

整个工具就是一个包含 HTML·CSS·JavaScript 的 `upscaler.html` 文件（约 6,140 行，360 KB）。没有外部库，也不需要服务器。只有界面字体（IBM Plex Sans KR）从 Google Fonts 获取，获取不到时使用系统字体。流式 PNG 保存使用 `CompressionStream`，并行计算使用 Web Worker，两者都没有时退回到较慢的路径。设备为深色模式时使用深色主题。

### 组成

| 层 | 主要函数 | 作用 |
|---|---|---|
| 色彩空间 | `S2L`, `L2S`, `enc16Linear` | sRGB ↔ 线性光表，16 位编码器 |
| 引擎 | `ENGINE_FACTORY`, `PORT` | 主线程·worker 共用的纯计算 |

| 复原 | `estimateNoise`, `sdctDenoise`, `qcsLuma`, `guidedFilter`, `restoreTile`, `richardsonLucy`, `denoise`, `deblock` | 噪声·JPEG·模糊 |
| 轮廓 | `edgeField`, `antialiasRegion`, `crispFields`, `steepenRegion`, `pixelTile` | 方向平滑，重绘，像素画 |

### 数据流与缓存

每张图片各自保存原图画布、JPEG 网格·质量、噪声模型（首次需要时计算一次）、主体框和设置。结果携带生成时的设置快照，因此之后即使改了设置，保存和重新计算也会得到与该结果相同的值。

结果分块放在 LRU 缓存中。缓存上限为内存预算的 60%；若实际创建画布失败，就把当时缓存大小的 80% 记为本设备的上限。在自动倍率选出的倍率下，按保证条件进一步降低上限。缓存装不下的结果，先从中央计算缓存的一半，其余在显示到画面上或保存时再计算。画面上可见但尚未算好的分块，先用原图放大填位，并在后台安排计算。

### 确定性：画面 = 保存结果

画面、保存、重新计算都使用同一个 `renderTile`。需要参考邻域的处理（插值、一致性、反锐化、方向平滑、重绘）会按所需半径多算一圈余量再裁掉，DCT 块网格和方向场固定在全局坐标上。因此结果与分块大小、顺序、worker 数无关。即使切成 64px 的小块计算，分块接缝也在 1 级以内，同一设置计算两次的差异为 0（[9.1](#91-不变量)）。

## 7. 问题与解决

### 画质

| 问题 | 原因 | 解决 |
|---|---|---|
| 轮廓周围的白边（振铃·光晕） | 核的负值尾部产生原图中没有的极值 | DCCI 4 邻域截断，单元范围限制，反锐化拐点限幅器 |
| 结果缩小后与原图不同 | 插值即使经过原图样本，面积平均也不吻合 | 在原图分辨率下精确求解一致性校正（Thomas） |
| 一致性与单元范围互相破坏 | 满足一个，另一个就偏离 | 交替投影两次 |
| 半透明边缘渗色（合成误差最大 29 级） | alpha 和颜色经过了不同的运算 | 让 alpha 也经过与颜色相同的运算（0.1~4 级） |
| 分步放大反而更差（−0.4~−0.8 dB） | 单元范围·一致性的基准放在了中间图像上 | 基准改为原图（+0.03~0.06 dB） |
| 线稿中原图的锯齿被复原出来 | 一致性把原图的锯齿视为正确答案 | 线稿·标志用重绘和方向平滑，并在搜索中按类型决定是否使用一致性 |
| 细线扭曲 | 50% 等值线重绘无法保持比 1 像素更细的线的浓度 | 用积分浓度测量线宽，细线保持不动 |
| 噪声中 DCCI 方向误判 | 噪声扰动方向变化量 | 在变化量上加噪声底 $`n_{\mathrm{off}}`$（Immerkær σ） |
| 把纹理误认为噪声而抹掉 | 纹理块使噪声谱膨胀 | 用 PCA 噪声底设上限，只用高频挑选 |
| JPEG 复原连文件中的细节也抹掉 | 仅靠去噪无法知道原本的系数 | 量化区间投影（QCS） |

### 色彩

| 问题 | 原因 | 解决 |
|---|---|---|
| 预设连颜色也改变 | 以前预设中包含白平衡 | 把色彩处理分离为独立功能，默认 0，只通过「色彩自动」按钮 |
| 把橙色的猫·晚霞误认为色偏 | 只用了平均估计器一种 | 三估计器共识（54 对中强色偏 13.9° → 4.0°） |
| 暗边界暗沉成团 | 在伽马空间插值 | 在线性光中计算 |
| 手机照片放大后变暗淡 | sRGB 画布把 Display P3 颜色压进 sRGB 内（P3 红色以 P3 值计为 234,51,35） | 读取原图配置文件，用 P3 画布处理并以 P3 配置文件（cICP·iCCP）保存（v1.1.0） |
| 放大后的天空出现阶梯状色带 | 8 位取整的色带按倍率变宽 | 由坐标决定的抖动（v1.1.0） |
| 叠加纹理后角点·暗处出现白点 | 窄而强的结构频段强度大，暗处同样的变化相对更大 | 对纹理强度做 5×5 腐蚀，把单像素变化限制在亮度（√）的 ±40% |
| 关闭「在线性光中计算」后纹理溢出 1.8 倍 | 把伽马值当作线性光，多做了一次 √ 和平方 | 伽马模式下亮度轴保持伽马值，比例也不平方。照片 12 例 R：修正前 2.24，修正后 1.32（线性光模式 1.22，v1.1.1） |
| 纹理改变明亮高饱和颜色的色相 | 即使三通道乘以同一比例，也只有最大的通道在上限处被截断 | 把提亮比例限制在最大通道的余量（alpha·1）内。亮红色 4× 时线性颜色比的最大变化 14.0% → 2.9%（8 位量化水平，v1.1.1） |
| 纹理强度在干净输入上溢出、在劣化输入上不足 | 最细的频段最先被模糊·JPEG 削掉 | 改在低一个倍频程的频段测量，减去结果中已有的高频，只补缺失部分 |

### 稳定性与输入输出

| 问题 | 原因 | 解决 |
|---|---|---|
| 应用一启动就卡死 | 启动时调用的 `updateSizeNote` 读取了较晚声明的 `let` 全局变量，引发 TDZ 错误 | 这类全局变量用 `var` 声明或放在前面 |
| 迟完成的测量应用到新图片上 | 异步测量的竞争 | 自动请求编号 `AUTO_SEQ` 与 `alive()` 检查 |
| 大画布不报异常却一片空白 | 浏览器隐藏的面积上限 | 若原图画布整体透明，就把原图按 1024² 片段直接读取，看是否有可见像素；保存拼装时在结果中找一个可见像素，确认画布上该位置后再记下上限。只有一个点可见的图片也能察觉（v1.1.1。以前只看右下角一个像素，该像素本来透明时就察觉不到） |
| AVIF 的广色域被判为 sRGB | 使用了文件中第一个出现的 colr 盒，而它可能属于缩略图 | 用 `pitm`·`ipma`·`ipco` 只看与主图像关联的 colr（v1.1.1） |
| PNG 的广色域被判为 sRGB | sRGB·iCCP 块位于 cICP 之前时就在那里停下 | 查看 IDAT 之前的所有色彩块后按 cICP > iCCP > sRGB。cICP 原色为未指定（2）·保留编号时改用 iCCP（v1.1.1） |
| 打开图片后立即更改的「分阶段放大」被还原 | 决定复选框初始值的测量迟完成并覆盖了它 | 每当用户·「自动」作出决定就递增编号（`STAGE_SEQ`），若与测量开始时不同或条件已变就不应用（v1.1.1） |
| 分步放大的透明图片边缘渗色·分块接缝 | 中间阶段只有 alpha 走了普通重采样 | alpha 也经过与颜色相同的运算（DCCI 4× 边缘颜色最大 19~38 → 1~4 级，标志接缝 206 → 1，v1.1.1） |
| 大文件解码不结束 | `onload`·`onerror` 都不触发的情况 | 按大小成比例的超时依次尝试三条路径 |
| worker 被禁止的环境 | 安全策略 | 5 秒响应检查后改用主线程 |
| 结果太大导致内存溢出 | 整个结果的画布 | 分块缓存与流式 PNG |
| 自动后改变倍率导致设置不匹配 | 自动按当时的倍率决定 | 用 `AUTO_LAST` 提示并让用户重新点击 |
| 干净输入的验证被当作 JPEG 输入处理 | 验证脚本对干净输入也传入了 JPEG 质量 85 | 不带 JPEG 信息重新验证，标志·漫画的搜索值只用于 JPEG 输入（v1.1.0） |

## 8. 优化

速度优化只在输出逐字节相同时才引入。把 134 种设置组合的 16 位输出和统计与基准版对照（`tests/engine_regression.js`）。但下表第一行的 DCCI 内部网格表是例外。这是经测量后采纳的折中：输出略有变化（±0.007 dB），换来速度提升；现在的基准版是加入此表之后的版本。

| 优化 | 内容 | 效果 |
|---|---|---|
| DCCI 内部网格表 | 6·8·12× 时用 4 倍网格代替 8 倍网格。25 个预设 × 1,800 对中在 ±0.007 dB 以内 | 快 25~30% |
| 共享 DCCI 方向权重 | 在引导平面上计算一次，用于所有通道 | |
| 单元范围缓存 | 每个通道平面只计算一次各单元的最小值·最大值 | |
| 一致性通道合并 | 不复制交织通道平面，直接共享覆盖区·系数·插值权重 | |
| 合计 | 1024×768 → 4×「标准」（표준） | 13.9 s → 12.0 s，134 种组合逐字节相同 |

此外，高斯用三次盒式模糊近似（Kutskir 方式），双边滤波的亮度权重查表，16 位条带按 128 行重新计算以节省内存。在 2× 以下也试过 4 倍网格，虽然平均提升 +0.013 dB，但变差的情况（24%）多于变好的情况（21%），且耗时翻倍，因此没有采用。

剩余瓶颈是 DCCI 插值（按通道）、一致性校正和重采样。在不改变输出的前提下很难大幅缩减。

### 9.4 大倍率复原搜索

**空间。** 核 4 × 一致性 2 × 单元范围 2 × 锐化量 19 ×（半径·阈值·过冲·方向平滑·重绘·反卷积倍数·降噪倍数·JPEG 复原倍数·分步放大）各 10 × 反卷积 σ 倍数 5 = **1,520,000,000,000 种**。

**约束。** 相对当前自动，SSIM 下降不超过 0.003，边界方向误差不超过 +10%。

**步骤。** 随机 1,500 个 → 前 150 个重新评估 → 从 4 个起点做坐标下降（所有步骤，直至收敛）→ 贴在滑块端点的值扩大范围后再来一遍。总计约 5.5 万次评估。记录（`data/big/search.jsonl`）已累积，可以接着运行。

### 9.5 分类器

用 `research/classifier` 的 27 个特征（`features2.py`）在 567 张图上训练。由同一原图产生的变体归为一组，按组做交叉验证，使同一幅图的不同版本不会同时进入训练和测试。分组交叉验证准确率为 **92.9%**。权重以内联 JSON 形式放在 `upscaler.html` 的 `AUTO_MODEL` 中，JS 判定与 Python 567/567 一致。

### 9.6 色彩处理

采用三估计器共识规则后，在 54 对测试中强色偏（与中性的夹角）从 13.9° 降到 4.0°。

### 9.7 8 位抖动

以同一处理的 16 位输出为基准，测量 8 位输出的误差（`tests/dither_probe.js`）。色带指标是把误差用高斯 σ2（结果像素）模糊后的 RMS。色带是覆盖大面积的低频误差，模糊后仍会保留；抖动的细腻纹理模糊后则会消失。共 20 例：合成的天空渐变，以及大倍率复原验证用的照片·绘画·插画片段 9 张放大 4·8 倍。

| 指标（20 例平均，级） | 取整 | 抖动 | 变化 |
|---|---|---|---|
| 色带指标 σ2 | 0.059 | 0.033 | −44%（8× 时约 −50%） |
| 色带指标 σ4 | 0.040 | 0.017 | −58% |
| 整体 RMS | 0.245 | 0.340 | +39% |

整体 RMS 因抖动叠加细腻噪声而相应增加。开启抖动后，最近邻 3× 输出的偏差值仍为 0 个，黑白输入的 R·G·B 最大差为 0。

### 9.8 纹理恢复

在大倍率复原数据（256px 真值 → 缩小 4·8 倍 → 再放大）上，用原图奈奎斯特频率以上频段（高斯 σ = 0.375·倍率的差分）的能量来测量（`research/texture/tex_probe.js`，结果 `research/results/texture*.json`）。

- **高频能量比 R** = 结果 / 真值。放大无法产生这一频段，因此 R 远小于 1。
- **纹理图误差** = 16×16 块高频能量的 log 比 RMS。用来看纹理是否出现在应有的位置。
- **PSNR·SSIM。** 编造的纹理与真值位置不一致，因此下降是正常的。

**常数标定。** 在照片搜索用 3 张 ×（4× 干净输入、4×·8× 现实劣化）共 9 例上，用割线法求使 R = 1 的常数，把能够对齐 R 的 8 例的中位数 $`C = 6.256`$ 定为 100%（v1.1.0 为 5.915。由于提亮时改为按通道余量缩小，数值略有增大）。设置与「自动」相同，是对缩小后的输入分类后选出的预设·搜索值。各图之间分布很广，在 2.4~12 之间。因为每张照片的纹理量不同，仅凭原图的一个频段无法准确估算缺失的能量。用真值图像来检验，在测试的四种预测式中，原图第二频段 × 倍频程数在照片上最准确（能量 ×÷1.45）。

**验证（照片验证用 3 张 × 4 种条件 = 12 例）。**

| 强度 | R | 纹理图误差 | 两者都变好的例数 | PSNR | SSIM |
|---|---|---|---|---|---|
| 关闭 | 0.11 | 1.04 | | | |
| 25% | 0.27 | 0.70 | 12/12 | −0.39 dB | −0.05 |
| 100% | 1.22 | 0.57 | 12/12 | −2.24 dB | −0.18 |

## 10. 特点与优势

**对信息诚实的复原。** 复原阶段不产生新的极值（单元范围），并使结果缩回后就是原图（一致性）。在此之上的校正只按用户开启的程度叠加。

**懂得图片类型的自动。** 依靠 9 类分类（92.9%）、1.52 万亿种设置的搜索，以及在每张图上的测量来决定。并在画面上写明依据。

**在原图分辨率下完成的复原。** 测量噪声谱后去噪的 DCT 复原、遵守文件量化表的 JPEG 复原、RL 反卷积都在放大之前进行。

**线条鲜活的图形。** 用方向平滑和符号距离重绘生成无锯齿的锐利线条。像素画对每个子样本只选用原调色板中的颜色，新颜色只出现在轮廓的抗锯齿上。

**诚实的用户设置。** 复选框和滑块完全按你的选择工作（刚打开图片时的例外见 [11. 局限](#11-局限)）。自动只由「自动」按钮执行，指示灯只告诉你测量结果。

**不受尺寸限制。** 借助分块缓存和按分块行的 PNG 压缩，不把未压缩的完整结果放入内存，也能保存数亿像素的结果。自动倍率只选择在内存预算下能处理到底的倍率。

**画面 = 保存。** 相同的核、余量和全局网格，使画面上看到的内容原样保存。

**没有色带的 8 位。** 用由坐标决定的抖动把色带指标降低近一半，同时精确的颜色、灰色和分块接缝保持不变。

**保留手机色彩。** 读取原图配置文件，把 Display P3 照片按 P3 处理，并附上自己生成的 P3 配置文件和 cICP 保存。

**隐私与便携。** 没有服务器也无需安装，图片不会离开设备。只有一个文件，便于保存和携带。

## 11. 局限

**不编造。** 原图中没有记录的细节（一根发丝、小字）无法恢复。它不像神经网络放大那样画入看似合理的形状，因此非常模糊的原图放大后依然模糊。

**纹理恢复是颗粒。** 纹理的量是匹配的，但位置和形状是编造的噪声，提高强度就会看起来像噪点。100% 时绘画会大幅溢出。插画效果很小，平涂图形在任何强度下都只有一半左右变好。只建议以低强度用于照片·绘画（[9.8](#98-纹理恢复)）。

**「观感」不增加信息。** 它只是把原图已有的轮廓与明暗重新画得更醒目，不会造出原图没有的细节。在线稿·文档·UI·标志这类轮廓本就很陡的图像上，只有略超过一半的情形得到改善（20/35）。像把极小原图大幅放大这种本就模糊的结果，用「观感」也依然模糊（[9.10](#910-观感锐度)）。

**标志·漫画仅限 JPEG 输入。** 在重新测量的干净输入上没有通过采纳规则，因此对 PNG 等干净输入不使用大倍率复原搜索值。原本是 JPEG、后来重新存为 PNG 的图片，即使有 JPEG 痕迹也视为干净输入。

**插画未采纳。** 各条件下结果参差不齐，因此不使用大倍率复原搜索值。还有用其他劣化（强噪声、其他模糊、原本就清晰的原图）和更大图像重新检验的余地。

**搜索范围。** 搜索以小片段（输入 64px）和每类 3 张为基准。锐化量·过冲等有贴在范围端点的倾向，扩大范围后提升也在 +0.1 dB 以内。

**只看内存的自动倍率。** 没有处理时间限制。8× 时结果达数百兆像素。内存预算是对设备内存的估计值，因此「保证」（보장）是以这个预算为基准的。因为浏览器不会准确告知剩余内存。

**8 位输入的灰阶。** 输入经由浏览器画布以 8 位读取。抖动和 16 位保存只是保护放大新生成的中间值，并不能消除原图中已有的色带（尤其是 1× 或非常平坦的区域）。关闭抖动后，8 位保存就是简单取整，色带会按倍率变宽。

**色彩管理。** 广色域只保护到 Display P3。含有超出 P3 颜色的原图（如 Adobe RGB·BT.2020·ProPhoto）会被压缩进 P3，保存的 PNG 附上 P3 配置文件。因为画布只提供 sRGB 和 Display P3 作为工作色彩空间。即便如此，压缩程度也比按 sRGB 读取小（以 CIE xy 面积计，BT.2020 三角形的 sRGB 占 53%，P3 占 72%）。要完整保留原配置文件，需要在不做色彩转换的情况下读取、按其编码处理并重新附上配置文件，因此留作单独的功能。不支持 P3 画布的浏览器（例如当前的 Firefox）按以前的方式以 sRGB 读取。粘贴的图片始终视为 sRGB。若 AVIF 没有 `colr` 盒、只在 AV1 比特流（序列头）中放置色彩信息，则不读取而视为 sRGB（libavif 等常见编码器会写 `colr`）。没有 `DecompressionStream` 的浏览器（Safari 15.2~16.3）无法解开 PNG 中压缩的 iCCP 配置文件，因此会把没有 cICP、仅靠 iCCP 标明广色域的 PNG 视为 sRGB。「自动」的分析（分类·细节测量·色彩自动）对 P3 图片也向浏览器请求 sRGB 值来测量，因此与分类器训练时的 sRGB 基准一致。没有流式压缩的浏览器的画布保存路径不会直接附上 P3 配置文件。

**压缩率假设。** 自动倍率把保存 PNG 的压缩率按在 47 张数据上分倍率测得的最大值再加 10% 余量计算（16 位且纹理开启时为 0.934 × 1.1，即压缩前大小的 102%）。噪声远多于这 47 张的图片，压缩效果会差于这一假设，即使在「保证」倍率下，保存期间的内存也可能不足。

**缺失的数据。** 分类器训练用的 RGBA 缓存（约 1.3 GB）和 DCCI 网格实验数据（约 1.3 GB）因体积原因不在仓库中。两者都可以由 `data/ds` 原图重新生成。

- **分步放大的透明图片。** 中间阶段 alpha 也经过与颜色相同的方向权重·单元范围·步间锐化。DCCI 4× 下半透明边缘颜色误差从最大 19~38 级降到 1~4 级，标志预设 4× 的分块接缝（最大 206 级）消失。
- **「分阶段放大」的初始值。** 若在打开图片后的测量完成前更改复选框或按下「自动」，迟完成的测量不会覆盖该选择。
- **空白画布检查。** 若原图画布整体透明，就把原图按片段直接读取，看是否有可见像素；画布保存时在结果中找一个可见像素并确认该位置。即使右下角本来透明或只有一个点可见，也能察觉画布上限。
- **纹理恢复中的亮色。** 把提亮比例限制在最大通道的余量内，使明亮高饱和颜色的色相不变。相应地重新标定了常数（5.915 → 6.256），并把测量修正为与「自动」相同的条件后重新测量。还修复了关闭「在线性光中计算」的伽马模式下纹理溢出 1.8 倍的问题。
- **色域判别。** 即使色彩信息之前有超过 2 MB 的元数据或盒（JPEG 扩展 XMP、PNG 文本块、meta 之前的 AVIF mdat），也会沿着头部找到。AVIF 看的是与主图像（而非缩略图·辅助图像）关联的色彩信息（colr）；PNG 与块顺序无关，最先看 cICP，但原色为未指定（2）时用 iCCP 配置文件判别。广色域文件即使 Blob URL 被拦截，也会用 Data URL `<img>` 读取以保住色彩。
- **「自动」之后的预算。** 「自动」从大倍率开始应用该倍率的「自动」设置试算，选出第一个有保证的倍率。在最近邻·纹理开启下把 1200×900 选成 8× 导致原图准备内存不足的情况不再出现。按倍率不同设置分成便宜·昂贵两种时停留在更小倍率的情况也不再出现（UI 图片 4000×3000，当前倍率 1.25×，三步分步放大：「无保证」→ 2×）。
- **自动倍率的内存计算。** 计入保存期间积累的压缩 PNG（把 47 张数据放大 1.1~4× 测得的各倍率最大压缩率加 10% 余量）和缓存中残留的其他已准备原图。因此对大照片选出的倍率可能降低（预算 600 MB 下 4000×3000 为 2× 而不是 4×）。更改保存位数或纹理时，提示也会重新计算。

### v1.1.0 — 无色带的 8 位、手机色彩、纹理恢复、标志重新验证
