# 확대기 (Upscaly)

무손실 지향 이미지 업스케일러입니다. `upscaler.html` 파일 하나로 동작하며, 모든 처리는 **브라우저 안에서만** 이루어집니다.
서버나 외부 라이브러리를 쓰지 않으므로 이미지가 기기 밖으로 나가지 않습니다.

## 사용법

1. `upscaler.html`을 내려받아 최신 브라우저로 엽니다. 설치는 필요 없습니다.
2. 이미지를 창에 끌어다 놓거나 붙여넣습니다. 한 번에 최대 20장, JPEG·PNG·WebP·AVIF를 지원합니다.
3. 배율을 고르고 **「자동: (권장, 추천)」** 을 누르면 이미지 종류를 판별해 알맞은 설정을 채웁니다.
4. **「확대 실행」** 후 **「원본 비교」** 로 결과를 확인하고 저장합니다. 8비트·16비트 PNG로 저장할 수 있습니다.

## 주요 기능

- **자동 설정** — 사진·일러스트·만화·선화·문서·UI·로고·픽셀 아트·회화 9종을 판별하고 이미지마다 측정해 설정을 조정합니다.
- **배율 자동** — 3~8× 가운데 기기 메모리 안에서 렌더링이 보장되는 가장 큰 배율을 고릅니다.
- **재구성 커널** — 엣지 적응 DCCI(권장), 픽셀아트 윤곽 복원, Lanczos-3/4, Catmull-Rom, Mitchell-Netravali, 최근접.
- **복원 단계** — 노이즈·잡티 정리, JPEG 흔적 복원, 디컨볼루션 선명도 복원, 계단 제거, 윤곽 강조, 단계로 나눠 확대.
- **색 처리** — 확대와 분리된 별도 기능이며 기본은 꺼져 있습니다. 「색 자동」 버튼으로만 적용됩니다.
- **투명 이미지** — 알파 채널도 색과 같은 연산을 거쳐 반투명 가장자리 색 번짐을 막습니다.
- **큰 이미지** — 멀티코어 워커와 타일 처리, 스트리밍 PNG 저장으로 결과 전체를 메모리에 올리지 않습니다.

## 참고

- 「보장」 배율은 브라우저가 알려 주는 기기 메모리 추정값 기준입니다. 8× 확대는 결과가 수백 메가픽셀이 될 수 있어 시간이 오래 걸립니다.
